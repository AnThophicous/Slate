# Benchmarks

`npm run benchmark` executa o ciclo de reconciliação do Slate em Node.js com 10.000 renders por padrão. O número pode ser alterado com `SLATE_BENCHMARK_ITERATIONS`.

Se Ink estiver instalado no ambiente, o script confirma a disponibilidade para que um benchmark de aplicação possa ser adicionado sem tornar Ink uma dependência do Slate.

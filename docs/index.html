Slate / release 2.3.0

Terminal interfaces with an explicit lifecycle.

Slate is a Rust terminal UI toolkit for Node.js, TypeScript and TSX. The API separates rendering one frame from running a live session, so a caller can see which resources it is opening.

One frame, no terminal session

Install the core and Slate runtime. This program renders ANSI and exits; it does not enter raw mode or poll input. The native addon is optional for this path.

npm install @slate-terminal/core @slate-terminal/react

// hello.mjs
import { Container, Text, render } from "@slate-terminal/react";

const app = render(
  Container({
    id: "app",
    children: Text({ id: "message", text: "Hello from Slate" })
  }),
  { viewport: { width: 40, height: 2 } }
);

process.stdout.write(app.renderAnsi({ clear: false, hideCursor: true }));
app.close();

A live session

Physical keyboard and mouse input require the optional N-API package. The session opens terminal modes; the controller owns polling and closes the Slate app.

npm install @slate-terminal/native

// live.mjs
import { createTerminalSession } from "@slate-terminal/core";
import { Container, Text, createSlateOutput, createTerminalController, render } from "@slate-terminal/react";

const app = render(Container({
  id: "app",
  children: Text({ id: "message", text: "Press Ctrl+C to exit" })
}), { viewport: { width: 40, height: 2 } });

const session = createTerminalSession();
const terminal = createTerminalController(
  app,
  session.input,
  createSlateOutput(process.stdout),
  { onExit: () => session.close() }
);

const shutdown = () => {
  terminal.close();
  session.close();
};

process.once("SIGTERM", shutdown);
terminal.start();

If the native addon is missing, createTerminalSession() throws. The ANSI one-shot path still works. In a Slate checkout, build the addon with npm run native:build; in an installed application, install @slate-terminal/native for the matching version and platform.

  • Rust layout and terminal primitives exposed to Node.js through N-API.
  • React-free runtime JSX; React itself is an optional integration.
  • One-shot ANSI rendering and live input share the same application tree.
  • Keyboard, mouse, resize, paste, focus and cleanup are explicit contracts.

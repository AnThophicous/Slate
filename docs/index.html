01 / Choose the boundary

Start small. Open the terminal only when you mean to.

render / return

One frame, no session

For snapshots, generated output, tests and tools that should render ANSI and exit without raw mode or native input.

import { Container, Text, render } from "@slate-terminal/react";

const app = render(Container({
  id: "app",
  children: Text({ id: "hello", text: "Hello, Slate" })
}));

process.stdout.write(app.renderAnsi());
app.close();
native addon: optionalsee the contract ↗
session / own

Live terminal session

For keyboard, mouse, paste, resize and focus. The session opens modes; the controller polls, presents and closes them.

const session = createTerminalSession();
const terminal = createTerminalController(
  app, session.input, createSlateOutput(process.stdout)
);

terminal.start();
// Ctrl+C or your action can close it.
terminal.close();

03 / Built for agents

Readable contracts beat clever guesses.

Slate tells an agent which API owns input, which one only renders, when native is required and what cleanup means. Less archaeology. Fewer defensive typeof branches.

Open the agent guide ↗
render()Builds the application tree. Does not start polling.
renderAnsi()Returns one frame. Does not own the terminal.
start()Connects input, commits output and installs lifecycle handling.
close()Stops work, restores resources and is safe to call again.
nativeOptional for rendering; required for physical terminal modes.

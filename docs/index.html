Slate 2.0: Rust Terminal UI for Node.js, TypeScript and TSX

Slate is a modular terminal user interface toolkit for building interactive command-line applications with React-free TSX, keyboard and mouse input.

The library combines a Rust core, Flexbox layout, signals, ready-made widgets, ANSI rendering, native Node.js bindings and the Slate Mosaic component tree.

Features

  • Rust terminal UI primitives with an additive LTS API.
  • Native Node.js integration for TypeScript and TSX applications.
  • Keyboard, mouse, resize, paste and focus events on Linux, Windows and macOS.
  • Flexbox layout with row, column, grow, shrink, gap, percentages, constraints and scroll.
  • Signals, computed state and selective presentation updates without React.
  • Input, Select, Checkbox, Tabs, Table, Spinner, Progress, Modal, ScrollView, List and Form.
  • Incremental ANSI rendering with duplicate-frame suppression and throttling.
  • Container-based Slate Mosaic trees with stable IDs and runtime editing.
  • Optional smooth Glow and ColorShift effects.

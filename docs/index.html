Slate / release 2.2.2

Terminal interfaces. Kept simple.

A modular Rust terminal UI toolkit with native Node.js bindings, TypeScript/TSX, Flexbox layout, signals, widgets and reliable keyboard and mouse input.

GitHub Production guide Releases
  • Rust core with ANSI rendering and native Node.js support.
  • React-free TSX, optional React 18/19 integration and stable IDs.
  • Keyboard, mouse, resize, paste, focus and emergency Ctrl+C close.
  • Flexbox layout, signals, widgets, multiline text and grapheme-safe wrapping.

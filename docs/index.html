Slate: Rust Terminal UI for Node.js, TypeScript and TSX

Slate is a modular terminal user interface toolkit for building interactive command-line applications with keyboard and mouse input.

The library combines a Rust core, ANSI rendering, native Node.js bindings, TypeScript APIs, TSX, containers, component trees and cross-platform terminal support.

Features

  • Rust terminal UI primitives with an additive LTS API.
  • Native Node.js integration for TypeScript and TSX applications.
  • Keyboard, mouse, resize, paste and focus events on Linux, Windows and macOS.
  • Incremental ANSI rendering with duplicate-frame suppression and throttling.
  • Container-based component trees with stable IDs and runtime editing.
  • Optional smooth Glow and ColorShift effects.
